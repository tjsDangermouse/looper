# Looper Loop API — v1

This is the public, versioned contract between the Looper clients and the
Looper Route Service. The service is the authority for behaviour; this file is
the change-review point for client-visible request and response changes.

Base URLs are client configuration, not part of the contract. Clients append
the paths below to their configured base URL.

## Compatibility

- New optional request fields and response fields are backwards compatible.
- Renaming, removing, or changing the meaning of a field requires `/v2`.
- Clients must ignore response fields they do not understand.
- Human-readable `error` and `warning` messages are suitable to show to a
  walker, but clients must not branch on their text.

## `POST /v1/loops`

Find up to three walking or running loops that begin and end at `start`.

### Request

```json
{
  "start": { "lng": -4.4816, "lat": 54.1506 },
  "mode": "distance",
  "distanceKm": 5,
  "units": "km",
  "activity": "walking",
  "walkingPaceMinutes": 12,
  "walkingPaceUnit": "km",
  "variation": 0,
  "exclude": [[[-4.48, 54.15], [-4.47, 54.16]]]
}
```

| Field | Required | Rules |
| --- | --- | --- |
| `start.lng`, `start.lat` | Yes | Longitude `-180…180`; latitude `-90…90`. |
| `mode` | Yes | `distance` or `time`. |
| `distanceKm` | With `distance` mode | Number from `0.5` to `30`. |
| `durationMinutes` | With `time` mode | Number from `10` to `360`. |
| `units` | Yes | `km` or `mi`; controls client-facing units. |
| `activity` | No | `walking` or `running`; omitted means walking. |
| `walkingPaceMinutes`, `walkingPaceUnit` | Together, optional | Pace in minutes per `km` or `mi`; `4…30` for walking and `2…30` for running. |
| `variation` | No | Integer `0…999`; omitted means `0`. Increment to request a different set. |
| `exclude` | No | At most three prior route outlines. Each is `[[lng, lat], …]`, with 2–120 points. |

`Content-Type` must be `application/json`.

### Success response — `200`

```json
{
  "routes": [
    {
      "id": "uuid",
      "label": "North-east loop",
      "distanceMeters": 5012,
      "durationSeconds": 3610,
      "targetDifferencePercent": 0,
      "geometry": { "type": "LineString", "coordinates": [[-4.48, 54.15]] },
      "steps": [
        {
          "instruction": "Turn left onto Quay Road",
          "distanceMeters": 120,
          "durationSeconds": 90,
          "maneuver": "turn-left",
          "road": "Quay Road",
          "roadClass": "residential",
          "startIndex": 4,
          "endIndex": 8
        }
      ]
    }
  ],
  "warning": "There’s no clean loop of that length from here, so these walks retrace part of the way back."
}
```

`routes` is always present and may be empty. `warning` is optional. A route
has a GeoJSON `LineString`; coordinates are `[longitude, latitude]`. `steps`
are ordered along the line. `maneuver`, `road`, `roadClass`, `startIndex`, and
`endIndex` are optional guidance enhancements and clients may safely ignore
them.

The service may include additional diagnostic or route-quality fields for its
own tools. Ordinary clients must ignore them.

### Error responses

All errors use `{ "error": "…" }`.

| Status | Meaning |
| --- | --- |
| `400` | Invalid request or unsupported starting location. |
| `405` | Method other than `POST`. |
| `429` | Rate limited; retry later. |
| `500` | Unexpected service failure. |
| `503` | Routing engine is busy or unavailable; retry later. |

## `GET /health`

Operational endpoint, not a client feature. Returns `200` when the routing
engine is ready and `503` when it is degraded.

## Ownership

The route-service maintainers own this contract. Web and iOS changes that add
or rely on API behaviour should update this document in the same change.
